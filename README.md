# CASE-AI质检增强版 - 钢铁焊接缺陷检测系统

基于 **YOLO + VLM** 的工业质检系统，融合百度钢铁缺陷检测大赛方案（得分 **33.48**），支持缺陷检测、可视化分析、数据导出和模型迭代优化。

## 📋 项目简介

本项目针对钢铁表面六大类缺陷进行检测，采用 YOLO12 模型架构，结合 VLM（视觉语言模型）实现可解释性强的缺陷分析。训练方案基于百度钢铁缺陷检测学习赛优化，最终得分 **33.48**。

### 赛题背景

缺陷检测技术广泛应用于工业场景，比如汽车制造中的车身表面缺陷检测、零件外观缺陷检测、工件裂纹检测等。其中，金属表面缺陷识别技术的应用可以在生产及制造阶段的质量控制方面发挥重要作用。

本数据集来自 **NEU表面缺陷检测数据集**，收集了6种典型的热轧带钢表面缺陷，即氧化铁皮压入(RS)、斑块(Pa)、开裂(Cr)、点蚀(PS)、夹杂(In)和划痕(Sc)。

不同类别的缺陷之间存在差异，比如斑块、开裂、点蚀等；相同类别的缺陷内部也存在差异，比如划痕缺陷可以是水平划痕、垂直划痕、倾斜划痕等。此外，由于受到光照和材料变化的影响，相同缺陷类别的图像，灰度也可能不同。

数据来源：http://faculty.neu.edu.cn/yunhyan/NEU_surface_defect_database.html

赛事官方链接：https://aistudio.baidu.com/competition/detail/808/0/introduction

## 🔬 核心训练策略

### 从头训练（非预训练模型）

本项目的核心训练程序 **不是** 先下载预训练的 YOLO 模型再训练，而是基于自定义的 YOLOv12 配置文件（`yolov12.yaml`）**从头训练**（`pretrained=False`）。

```python
# 从 yaml 配置创建模型，从零开始训练
model = YOLO('yolov12.yaml')  # pretrained=False
```

**为什么选择从头训练？**

- **领域适配性**：钢铁缺陷检测与COCO等通用数据集的目标特征差异巨大，预训练权重可能引入不相关的先验知识
- **避免负迁移**：COCO预训练模型学习的是日常物体特征，直接微调可能导致模型对工业缺陷特征不敏感
- **完全学习领域特征**：从头训练让模型完全聚焦于钢铁表面缺陷的特征学习，更适合工业场景

### YOLO 数据增强原理详解

数据增强是提升模型泛化能力的关键手段。本项目采用 **在线增强** 策略，即在训练过程中实时对数据进行变换，每个epoch的增强效果都不同，相当于让模型看到"不同版本"的同一张图片。

#### 基础增强（5个参数）

| 参数 | 值 | 原理说明 |
|------|-----|---------|
| `mosaic` | 1.0 | 将4张训练图片随机拼接成1张。**作用**：增加小目标出现频率，提升模型对小缺陷的检测能力；同时增强模型对复杂背景的理解 |
| `mixup` | 0.1 | 将两张图片按随机比例混合。**作用**：增加样本多样性，防止模型过拟合；让模型学习更平滑的决策边界 |
| `copy_paste` | 0.1 | 将图片中的缺陷区域复制粘贴到其他图片上。**作用**：增加稀有缺陷类别的样本数量，缓解类别不平衡问题 |
| `scale` | 0.5 | 随机缩放图片尺寸（0.5~1.5倍）。**作用**：模拟不同拍摄距离下的缺陷，提升模型对多尺度缺陷的适应能力 |
| `fliplr` | 0.5 | 50%概率水平翻转。**作用**：缺陷在水平方向上无固定朝向，翻转可有效扩充数据集 |

#### 微调增强（3个关键参数）

| 参数 | 值 | 原理说明 |
|------|-----|---------|
| `flipud` | 0.5 | 50%概率垂直翻转。**作用**：缺陷在垂直方向上也无固定朝向，与水平翻转配合实现全方位数据扩充 |
| `degrees` | 12.0 | 随机旋转-12°~+12°。**作用**：模拟相机拍摄角度变化，让模型对缺陷的旋转不变性更强 |
| `hsv_s` | 0.5 | 饱和度增强（±50%）。**作用**：钢铁表面受光照影响大，增强饱和度变化可提升模型对不同光照条件的鲁棒性 |

#### 数据增强的整体效果

```
原始图片 ──┬── Mosaic ──→ 4张拼成1张，增加小目标
           ├── MixUp ──→ 两张混合，平滑决策边界
           ├── Copy-Paste ──→ 复制缺陷，平衡类别
           ├── Scale ──→ 随机缩放，多尺度适应
           ├── Flip ──→ 翻转，方向不变性
           ├── Rotate ──→ 旋转，角度不变性
           └── HSV ──→ 颜色变换，光照鲁棒性
```

通过这些增强策略的组合，模型在训练过程中能够看到远超原始数据集的样本变化，从而显著提升泛化能力和检测精度。

## 🎯 优化策略

1. **增加训练轮数**: epochs 从 100 提升至 200
2. **数据增强**: 5个基础增强参数 + 3个关键微调参数（详见上方原理说明）
3. **模型集成**: 支持 yolo12n + yolo12s 多模型 WBF 融合
4. **动态置信度调优**: 自动搜索最优置信度阈值
5. **TTA 推理增强**: Test Time Augmentation 提升推理精度

## 🏭 国家标准融合与工业落地能力

本系统不仅是一个AI检测模型，更是一个**符合国家标准、具备工业落地能力**的质检解决方案。

### 融合的国家标准

| 标准编号 | 标准名称 | 应用场景 |
|---------|---------|---------|
| GB/T 14977-2008 | 热轧钢板表面质量的一般要求 | 缺陷分级（A/B/C/D/E）、深度/面积限度、修整规则 |
| GB/T 3274-2017 | 碳素结构钢和低合金结构钢热轧钢板和钢带 | 表面缺陷允许限度、清理要求、带缺陷交货比例 |
| GB/T 10561-2023 | 钢中非金属夹杂物含量的测定 | 夹杂物分类（A/B/C/D/DS）、显微评级、合格级别 |
| GB/T 8923.1-2011 | 涂覆涂料前钢材表面处理 表面清洁度的目视评定 | 锈蚀等级（A/B/C/D）、清理等级（Sa/St/Pt） |
| GB/T 8923.3-2009 | 涂覆涂料前钢材表面处理 表面清洁度的目视评定 第3部分 | 缺陷处理等级、清理要求 |

### 缺陷量化分析

系统对每个检测到的缺陷进行**多维度量化分析**，输出工业检测所需的关键参数：

| 量化指标 | 说明 |
|---------|------|
| 缺陷尺寸 | 宽×高（像素/mm） |
| 缺陷面积 | 像素²/mm² |
| 相对面积 | 占图片/工件面积比例 |
| 长宽比 | 缺陷形态特征 |
| 严重程度 | 轻微/中等/严重（基于国家标准阈值） |
| 是否超标 | 自动判定是否符合国标要求 |

### 国家标准自动判定

系统根据缺陷类型和量化指标，**自动匹配国家标准**并输出：

- **国家标准判定**: 基于GB/T 14977-2008等标准，自动判定缺陷等级（A/B/C/D/E级）
- **技术处理建议**: 针对每个缺陷，给出清除、打磨、补焊、判废等具体技术方案
- **流程处理建议**: 判废/返工/让步接收等流程决策建议
- **参考标准**: 明确列出适用的国家标准条款

### 缺陷分级与处理对照表

| 缺陷类型 | 国标等级 | 判定标准 | 处理建议 |
|---------|---------|---------|---------|
| 龟裂 | A级 | 不允许存在 | 必须完全清除，深度超公差判废 |
| 夹杂 | A级 | 不允许存在 | 表面夹杂必须清除，面积超限判废 |
| 氧化铁皮压入 | A级 | 不允许存在 | 必须完全清除，深度>0.3mm判废 |
| 点蚀 | B/C/D/E级 | 按深度和面积分级 | B级允许存在，C级打磨，D/E级补焊或判废 |
| 划痕 | B/C级 | 按深度分级 | B级无需处理，C级打磨，深度>0.3mm判废 |
| 斑块 | B/C级 | 按面积分级 | 面积≤0.5cm²无需处理，>0.5cm²打磨 |

### 工业场景工作流

```
日常检测 → AI自动检测 → 缺陷量化分析 → 国家标准判定 → 处理建议输出
    ↓
人工审核 → 正确/误检/漏检标记 → Bad Case导出 → 重新标注 → 模型重训练
    ↓
模型迭代优化 → 部署新版本 → 持续提升检测精度
```
